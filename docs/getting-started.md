# 登录与开始使用

## 打开内测版本

访问 [CanvasBest](https://best-aigc-canvas.vercel.app/)，使用内测管理员提供的邮箱和密码登录。当前不开放自主注册。

登录成功后，系统会打开该账号最近使用的本地画布；如果没有画布，会自动创建一张新画布。

## 登录和退出

- 刷新页面后，登录状态会自动恢复。
- 可以直接访问 `/canvas` 或具体画布地址。
- 退出登录不会删除该账号保存在当前浏览器中的画布和资产。
- 同一账号再次登录后会恢复原有本地数据。

## 第一次使用建议

1. 新建或打开一张画布。
2. 添加一个文本节点，输入用于测试的提示词。
3. 添加生成配置节点并连接文本节点。
4. 完成一次文本或图片生成。
5. 将结果加入“我的资产”。
6. 刷新页面，确认画布和结果仍然存在。
