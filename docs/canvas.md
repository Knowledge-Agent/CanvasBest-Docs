# 画布基础操作

## 创建和管理画布

画布库支持创建、重命名、删除、导入和导出画布。每张画布独立保存节点、连线、背景和视口位置。

## 选择与移动

- 使用底部工具栏切换“选择”和“移动”模式。
- 选择模式可以点击节点或拖出范围框进行多选。
- 移动模式可以从画布背景或节点上拖动画布。
- 按住 `Control` 或空格可以临时反转当前工具。
- 鼠标滚轮用于缩放，左下角会显示当前缩放比例。

## 节点与连线

常用节点包括文本、图片和生成配置节点。拖动节点左右两侧的连接点即可建立上下游关系。

支持的常用操作：

- 移动和调整节点尺寸。
- 复制、粘贴、删除节点。
- 撤销和重做。
- 查看节点信息和生成参数。
- 将图片节点保存到“我的资产”。

## 保存与恢复

画布会自动保存在当前浏览器中。刷新页面后，节点、连线、尺寸、生成配置、图片和视口应恢复到刷新前的状态。

建议定期使用画布导出功能保存 JSON 备份，特别是在清理浏览器数据或更换设备之前。
