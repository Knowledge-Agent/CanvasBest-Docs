# 我的资产与生成历史

## 我的资产

“我的资产”用于保存常用文本、图片和视频。可以：

- 新增文本资产或上传图片、视频资产。
- 将画布或工作台中的生成图片和视频加入资产。
- 编辑标题、标签、来源和备注。
- 将资产重新插入当前画布。
- 下载图片或视频。
- 导出或导入 CanvasBest 资产包。

“导入资产包”只用于导入由 CanvasBest 导出的 ZIP 文件；直接上传单张图片或视频请使用“新增资产”。

## 生成历史

生图工作台和视频创作台会保存提示词、参考素材、生成设置和结果。打开历史记录后，可以恢复当时的输入和结果并继续创作。

视频生成期间刷新页面会继续查询原任务，不会新建任务或重复扣费。完成的视频保存在当前浏览器中；如果本地文件意外缺失，系统会尝试使用原任务恢复。

## 刷新恢复

将生成结果保存到资产后重新插入画布，刷新或切换画布后仍应正常显示。退出当前账号并重新登录同一账号，也应恢复该账号在当前浏览器中的资产、生成历史和画布。

删除其他资产、画布或生成历史时，仍被其他位置引用的媒体文件会继续保留。

资产、历史和媒体目前不会自动同步到其他浏览器或设备。
