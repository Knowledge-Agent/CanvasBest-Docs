# 常见问题

## 为什么不能自行注册？

当前处于封闭内测阶段，账号由管理员创建。

## 登录后为什么看不到另一台设备上的画布？

画布和资产目前主要保存在浏览器本地，账号暂不提供云端数据同步。

## 图片生成需要多久？

通常需要几十秒到两分钟。只要页面仍显示生成中，可以继续等待。频繁出现长时间卡死或 `502` 时请反馈。

## 为什么同一提示词反复失败？

可能是上游模型暂时不可用、任务失败或内容审核。可以先确认积分已经退款，再调整提示词或稍后重试。

## “导入资产包”和“新增资产”有什么区别？

“导入资产包”读取 CanvasBest 导出的 ZIP 文件；“新增资产”用于手动添加文本或上传单张图片。

## Agent 在哪里？

Agent 不属于当前内测范围，页面入口已经关闭。

## 是否支持视频和音频？

项目仍保留部分视频和音频能力，但本轮只重点验收文本与图片核心链路，视频音频不作为当前内测承诺。

## 如何反馈问题？

联系为你开通账号的内测管理员，提供复现步骤、错误提示和已隐藏敏感信息的截图。不要发送密码、登录 Token 或 API Key。
