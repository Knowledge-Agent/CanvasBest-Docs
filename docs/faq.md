# 常见问题

## 为什么不能自行注册？

当前处于封闭内测阶段，账号由管理员创建。

## 登录后为什么看不到另一台设备上的画布？

画布、资产和生成媒体目前主要保存在浏览器本地，账号暂不提供云端数据同步。

## 图片或视频生成需要多久？

图片通常需要几十秒到两分钟，视频通常需要更长时间。只要页面仍显示生成中，可以继续等待；视频生成期间刷新页面会继续查询原任务。频繁出现长时间卡死或服务错误时请反馈。

## 为什么同一提示词反复失败？

可能是上游模型暂时不可用、任务失败或内容审核。可以先确认积分已经退款，再调整提示词或稍后重试。

## 视频生成需要填写 API Key 吗？

不需要。当前托管视频由平台统一配置模型和密钥，用户只消耗账户积分。自定义渠道以及尚未托管的能力仍可能需要浏览器本地配置。

## 为什么刷新后视频仍然可以播放？

完成的视频会保存到当前浏览器的 IndexedDB，并通过本地 `blob:` 地址播放。如果本地文件意外缺失，系统会尝试使用原任务恢复，不会重新生成或再次扣费。

## “导入资产包”和“新增资产”有什么区别？

“导入资产包”读取 CanvasBest 导出的 ZIP 文件；“新增资产”用于手动添加文本或上传图片、视频。

## Agent 在哪里？

Agent 不属于当前内测范围，页面入口已经关闭。

## 是否支持视频和音频？

当前内测支持托管视频的文生视频和单张参考图生成。参考视频、参考音频和托管音频暂未开放。

## 如何反馈问题？

联系为你开通账号的内测管理员，提供复现步骤、错误提示和已隐藏敏感信息的截图。不要发送密码、登录 Token 或 API Key。
