# 文本生成

## 通过文本节点生成

选择文本节点并使用生成入口，可以把当前文本作为提示词发起托管文本请求。生成结果会写入新的文本节点，并与原节点保持连接。

## 通过生成配置节点生成

1. 将一个或多个文本节点连接到生成配置节点。
2. 在生成配置节点中选择“文本”。
3. 检查模型和推理强度。
4. 点击“开始生成”。

每次文本模式生成只创建一个下游文本节点。完整组合提示词会记录在节点信息中，节点名称保持简洁并可手动修改。

## 上游文本顺序

- 没有使用 `@` 引用时，系统按连接顺序加入全部直接上游文本，并使用带编号的文本边界区分内容。
- 使用 `@` 引用时，只在编辑位置展开被引用的内容，并保持输入框中的顺序。

## 积分和失败

请求发起前会预扣积分；成功后确认消费，上游失败时自动退款。失败节点会保留错误状态，可以稍后重试。
