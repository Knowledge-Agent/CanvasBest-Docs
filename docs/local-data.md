# 本地数据与账号隔离

## 数据保存位置

当前画布、资产、媒体文件和生成历史主要保存在浏览器的 IndexedDB 中。登录账号用于身份验证、积分归属和本地数据隔离，不代表已经支持云端画布同步。

## 同一账号

- 在同一浏览器重新登录后，可以恢复原有数据。
- 同一账号打开多个标签页时，画布和资产会在标签页之间同步。
- 换一台设备、换一个浏览器或使用无痕窗口时，不会自动出现原有数据。

## 不同账号

不同账号在同一浏览器中的画布、资产和生成历史相互隔离。退出登录不会删除数据，重新登录对应账号后才会重新载入。

## 避免数据丢失

- 不要随意清除站点数据、IndexedDB 或浏览器配置。
- 更换设备或浏览器前，先导出重要画布和资产包。
- 不要把无痕窗口作为长期创作环境。
- 用户自行配置的第三方 AI API Key 保存在浏览器中，请只在可信设备上使用。
