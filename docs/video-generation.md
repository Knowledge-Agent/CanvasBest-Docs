# 视频生成

## 当前能力

CanvasBest 的视频能力由平台统一提供模型与密钥。内测用户只消耗账户积分，不需要填写视频供应商的 API Key。

第一版支持：

- 文生视频。
- 使用 1 张参考图生成视频。
- 480p 和 720p。
- 4、5、6、8、10、15、30 秒。
- 横屏、竖屏、方形和自适应等页面提供的比例。

参考视频和参考音频暂未开放。

## 视频工作台

1. 打开顶部“视频创作台”。
2. 输入提示词，也可以上传 1 张参考图。
3. 选择分辨率、比例和时长。
4. 确认页面显示的预计积分后开始生成。
5. 生成期间可以刷新页面，重新进入后会继续查询原任务。
6. 完成后可以播放、下载或加入“我的资产”。

请勿连续重复点击生成按钮。一次生成只会创建一个任务并结算一次积分。

## 在画布中生成

将文本节点连接到生成配置节点，切换为视频模式后即可生成视频。也可以连接 1 张图片作为参考图。生成完成后，结果会作为视频节点插入画布。

平台托管视频不会要求配置浏览器渠道或 API Key。

## 积分

- 480p：每秒 5 积分。
- 720p：每秒 10 积分。
- 例如 5 秒视频分别需要 25 或 50 积分。
- 余额不足时不会创建生成任务。
- 生成成功后确认消费；明确失败时自动退款。
- 刷新恢复、历史恢复和本地文件恢复不会重复扣费。

## 保存与恢复

完成的视频会完整保存到当前浏览器的 IndexedDB，并通过本地 `blob:` 地址播放，不依赖供应商临时视频链接。

- 刷新、切换记录或重新登录同一账号后仍可恢复。
- 视频可以保存到“我的资产”，也可以下载为本地文件。
- 删除其他资产、画布或生成记录，不会删除仍被其他位置引用的视频。
- 如果本地视频意外缺失，系统会尝试使用原任务恢复；任务已经过期时会显示明确提示。

视频目前不会自动同步到其他浏览器或设备。清除站点数据、IndexedDB 或使用无痕窗口，仍可能导致本地视频丢失。
