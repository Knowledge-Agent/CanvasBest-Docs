# CanvasBest Documentation

CanvasBest is an AI-native visual creation canvas maintained by XGEN Labs. It keeps prompts, references, generation settings, and creative results in one continuous workflow.

[Open the private beta](https://best-aigc-canvas.vercel.app/) · [中文文档](README.md) · [Changelog](CHANGELOG.md)

The current beta focuses on canvas workflows, managed text and image generation, reusable assets, credit settlement, and reliable refresh recovery. Canvases and assets are primarily stored in the current browser and are not automatically synchronized across devices.

For detailed instructions, use the Chinese guides in the [`docs/`](docs/) directory or contact your beta administrator.
